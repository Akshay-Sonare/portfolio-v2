# Akshay Sonare — Portfolio

Personal portfolio site for Akshay Sonare, Salesforce Solutions Architect.

A single static `index.html` with no build step. Open it in a browser to preview.

## Deploying with GitHub Pages

1. Make the repo public (or use GitHub Pro for private Pages).
2. Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
3. Add a `CNAME` file containing your domain and set the same domain under Custom domain.
4. In GoDaddy DNS, add A records for `@` pointing to 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153, and a CNAME for `www` pointing to `akshay-sonare.github.io`.
5. Once DNS resolves, enable Enforce HTTPS.

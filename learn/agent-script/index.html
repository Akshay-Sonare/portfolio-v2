The big idea: two kinds of lines

Most of an agent script falls into one of two lanes. Some lines are instructions the AI reads and interprets. Others are logic that runs exactly the same way every time. Mixing them is the whole point: you decide what must be predictable and what can be flexible.

Logic · runs every time

Deterministic

Starts with ->. Conditions, assignments and routing run before the AI sees anything, so the outcome never depends on the model's mood.

Prompt · goes to the AI

Flexible

Starts with |. Plain-language instructions the AI follows, with live values dropped in using {!…}.

Symbols cheat sheet

The handful of symbols that do most of the work.

SymbolWhat it meansExample
->Start a block of logic that runs on every turn.instructions:->
|Prompt text: sent to the AI as instructions.| Ask for the order number.
...Slot fill: the AI picks the value from the conversation.with order_number=...
@Reference something: a variable, action, output, subagent or utility.@variables.order_status
{!…}Insert a live value into prompt text.{!@variables.order_number}
setAssign a value, often from an action's output.set @variables.x = @outputs.status
withPass an input to an action.with format="pdf"
available whenHide an action until a condition is true.available when @variables.x != ""
#Comment. Ignored by the agent.# Routes the customer

Four kinds of template

You build prompt templates in Prompt Builder. The type decides where a template can be used and what inputs it gets.

Sales Email

Drafts an email in the context of a record, such as a contact or opportunity.

Field Generation

Fills in a field on a record page, like a case summary.

Record Summary

Summarizes a record for whoever is looking at it.

Flex

Takes the inputs you define. The most flexible type, and the one agents and Flows usually call. This lesson uses it.

Ground it with Apex

Merge fields cover simple values. For anything you have to look up, an Apex class can supply the data. The template refers to it as {!$Apex:OrderDetailsProvider.Prompt}.

Check for your template type: depending on the type, Salesforce may also expect a CapabilityType value on the @InvocableMethod annotation. Salesforce's own recipe for a Flex template doesn't use one, so this lesson leaves it out. Confirm in the Prompt Builder docs before you ship.
